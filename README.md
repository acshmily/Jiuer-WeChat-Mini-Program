# 咎儿助手

离线个人决策小程序：把纠结摊开，交给一位奇策士拆账、定夺、留档。

## 功能

- **做决定** — 写下议题与至少两条可走之路，按种子加权算出各路占比与首选；不服可「再算一局」（换种子重排）。
- **正反拆解** — 逐路写利与弊，按利弊内容给出规则型短评；可把路名交接给决定页预填。
- **谋略札记** — 本地短记，按「人 / 局 / 险」三类归档。
- **定论海报** — Canvas 2D 绘制结果图，可分享好友或保存相册。

## 特性

- 纯本地：数据只存 `wx.setStorageSync`，无账号、无后端、不上传。
- 确定性评分：CRC32 种子加权，同一议题 + 选项顺序 + 种子恒得同一占比。
- 文案收口在 `utils/togameVoice.js`，产品气质原创。

## 开发

1. 用微信开发者工具导入本仓库目录（`project.config.json` 已含 AppID 与基础库配置）。
2. 页面结构见 `app.json`：决定（表单 / 定论 / 历史）、拆解、札记（列表 / 编辑）。
3. 评分、存储、文案、海报、抹去动效等逻辑都在 `utils/` 与 `components/tg-dissolve`。
